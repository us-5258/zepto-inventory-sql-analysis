# Zepto Inventory SQL Analysis

## 📌 Project Overview
SQL-based inventory analysis of Zepto product data using MySQL.

## 🛠️ Tools & Technologies
- MySQL
- MySQL Workbench
- SQL

## 📊 Analysis Performed
- Product and category analysis
- Inventory value calculation
- Category-wise inventory analysis
- Out-of-stock product analysis
- Discount analysis
- Ranking using window functions
- Average inventory value by category
- Low-stock product identification

## 🔍 SQL Concepts Used
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- Aggregate Functions
- CASE statements
- CTEs
- Window Functions
- RANK()
- Views
- ROUND()
- LIMIT

## 📁 Files
- `zepto_inventory_analysis.sql` — Complete SQL queries used for the analysis.
